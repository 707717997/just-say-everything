# SayAll 语音指令（SayAllVoice）

把「按住语音键说话」变成「说一句就执行」：说 **打开微信** 就开微信，说 **截图** 就截图，
说 **锁屏** 就锁屏。说不中指令时，文字照旧打进原来的输入框，日常听写一点不受影响。

它不修改 SayAll，而是作为一个**伴随程序**跑在托盘里，和 SayAll 共用同一个语音键
（你现在的设置是 **左Ctrl + 左Win**，也就是遥控器上的语音键）。

---

## 常用语音指令

按住小米遥控器语音键，说完松手：

| 想做什么 | 说什么 |
| --- | --- |
| 打开程序 | 「打开微信」「打开 Claude」「打开 DeepSeek」「打开记事本」 |
| 回到桌面 | 「回到桌面」「回桌面」 |
| 切到上一个程序 | 「切换到上一个程序」「上一个程序」「切回去」 |
| 聚焦输入框 | 「聚焦输入框」「输入框」 |
| 打开 Claude 置顶会话 | 「打开置顶的第一个会话」…「第五个」，也可说「第二个会话」「置顶三」 |

- 置顶会话按 Claude 左栏「已置顶」的顺序（最近活动在前）；展开出来的子会话不计数。
- 聚焦输入框：Claude、DeepSeek Harness、微信点窗口底部的输入框；浏览器跳到地址栏；其他程序找最靠下的输入框。
- 目标窗口不在前台时不会点击，只提示失败，避免点错地方。

## 语音对话（第二版）

**两只耳朵**：微信输入法听写之外，程序同时旁听遥控器声音，用本地 SenseVoice 识别（`asr` 文件夹，不联网）。输入法没出字时自动用本地结果。

**它会回答你**：

| 想做什么 | 说什么 |
| --- | --- |
| 问时间 | 「现在几点」「今天星期几」 |
| 问电脑 | 「电脑状态」「当前是什么窗口」 |
| 问会话 | 「置顶有哪些会话」「读第二个会话」「第二个会话说了什么」 |
| 读剪贴板 | 「读剪贴板」 |
| 重复 | 「再来一次」重做上一条；「再说一遍」重听回答；「别说了」停止朗读 |
| 连续做 | 「打开微信然后聚焦输入框」，用「然后」连接，最多 4 步 |
| 打开网址 | 「打开 baidu.com」 |

**打开面板和网站**：已经开着就切过去，没开才新开。

- 说端口或名字：「打开 3000」「打开前端」。面板列表写在 `%APPDATA%\SayAllVoice\panels.json`（格式见 README），改完 5 分钟内生效，不用重启。
- 网站：「打开抖音」「打开微云」「打开 ChatGPT」「打开 OpenCode」「打开推特」。
- 找标签页时 Chrome 会快速翻一圈。面板没响应只提示，不会重启它。

**刷抖音**：

| 在抖音页面上说 | 效果 |
| --- | --- |
| 「下一个」「上一个」 | 翻视频 |
| 「暂停」「继续」 | 暂停和播放 |
| 「点赞」「收藏」「关注」「评论」 | 再说一次就是取消 |
| 「全屏」「网页全屏」「清屏」「弹幕」「连播」 | 开关 |
| 「快进」「快退」「不感兴趣」「作者主页」「相关推荐」「稍后再看」「小窗」 | 同抖音快捷键 |

不在抖音页面时，「暂停」「全屏」还是原来的含义。「下一个视频」「上一个视频」「点赞」「不感兴趣」或带前缀的「抖音暂停」会自动去找抖音。

**它会问你**：

- 没把握时问「你是想……吗？」，说「是」「第二个」「不是」回答，回车和 Esc 也行。12 秒不答自动取消。
- 问过一次确认的说法会记住（`learned.json`），下次直接执行。
- 关机、重启、注销、睡眠一定先问，「再来一次」也绕不过去。
- 像指令但听不懂的短句不再直接粘贴，会问要不要输入。微信里照常听写。

托盘菜单可以关掉「语音回答」和「记录使用情况」。使用记录存在 `%APPDATA%\SayAllVoice\activity`，只有前台程序、窗口标题、切换次数和带 Ctrl/Alt/Win 的快捷键次数，不记打字内容，不截图，不录音，30 天后自动删除。汇总用 `assets\activity_report.py`。

## 一、它是怎么工作的

```
遥控器语音键
   ↓（SayAll 把按键转成 Ctrl+Win）
SayAllVoice 的低层键盘钩子听到 → 立刻在屏幕顶部弹出「指令面板」并抢到焦点
   ↓
SayAll 同时让微信输入法进入语音状态，说的话被识别后写进「当前焦点」
   ↓（因为焦点已经被面板抢走，文字就落进面板的输入框）
面板实时拿文字去比对指令库
   ↓
命中 → 执行（开应用 / 按键 / 系统动作 / 打开网址）
没命中 → 把文字原样送回你原来的窗口（等于什么都没发生，只是慢半拍）
```

面板抢不到焦点时也一样安全：文字直接进原窗口，行为和现在完全一致。

## 二、怎么用

| 操作 | 说明 |
| --- | --- |
| **按住遥控器语音键说话** | 面板弹出，说完松手，命中指令就执行 |
| **回车** | 执行当前选中的候选 |
| **↑ ↓** | 在候选里挑一条（默认高亮最像的那条） |
| **Esc** | 取消，什么都不做 |
| **F1** | 打开指令库 |
| **Ctrl + Alt + M** | 不用麦克风，手动敲字执行（调试/应急用） |
| 托盘图标右键 | 语音指令开关 / 指令库 / 手动输入 / 重建应用索引 / 开机启动 / 配置文件夹 / 退出 |

说错的例子：

- 说「帮我打开一下微信吧」→ 自动去掉「帮我」「一下」「吧」，按「打开微信」匹配。
- 说「打开微信。」→ 标点会被忽略。
- 说「打开豆包」→ 内置库里没有，但会用**应用索引**（开始菜单 + 注册表里 363 个程序）去找。
- 说「帮助」「有哪些指令」→ 直接把指令库窗口调出来，忘了怎么说就看一眼。

## 三、指令库（重点）

托盘右键 → **打开指令库**，或按面板上的 F1。

- 左边是全部指令，可以按分类筛选、按名字/别名搜索。
- 右边是编辑器：名称、别名、分类、动作、参数、提示语、是否启用，底部有 JSON 预览。
- **内置指令是只读的**，想改就点「复制为自定义」，改完保存，存在
  `%APPDATA%\SayAllVoice\commands.json`，升级不会丢。
- 「+ 新建指令」可以自己加，比如把「打开 B 站」绑成 `https://www.bilibili.com`。
- 「重建应用索引」会重新扫开始菜单和注册表（新装的软件认不出来时点一下）。

### 动作类型

| 动作 | 参数写什么 | 例子 |
| --- | --- | --- |
| 打开应用 | 应用名，或 `@app:名字` | `微信`、`@app:Chrome` |
| 打开网址 | 网址 | `https://www.bilibili.com` |
| 发送按键 | 组合键 | `ctrl+shift+esc`、`win+d`、`alt+tab` |
| 输入文字 | 要打出来的字 | `我的邮箱是 xxx@qq.com` |
| 系统动作 | 操作名 | `lock`、`sleep`、`screenshot`、`mute`、`taskview` |
| 等待 | 毫秒 | `800` |

### 内置了什么（节选）

- **应用**：微信、企业微信、QQ、Chrome、Edge、记事本、计算器、画图、资源管理器、
  命令提示符、PowerShell、任务管理器、设置、截图工具、Word/Excel/PowerPoint、
  VS Code、钉钉、飞书、网易云音乐、Bandizip
- **系统**：锁屏、睡眠、关机、重启、注销、静音、音量±、播放/暂停、上一首/下一首、
  窗口置顶、Alt+F4、最大化、最小化、显示桌面、任务视图、Alt+Tab、
  截图（Win+Shift+S）、全屏截图、录屏、Win+R、Win+S、Win+E、Win+A、Win+V、Win+.、Win+P
- **编辑**：复制、粘贴、剪切、撤销、重做、全选、保存、查找、替换、加粗、斜体、下划线…
- **窗口 / 网页**：新标签页、关闭标签、刷新、后退、前进、放大、缩小、恢复 100%、
  地址栏、历史记录、下载、开发者工具、百度/谷歌/B站/淘宝/京东/知乎 搜索

### 动态指令（不用预先配置）

- 说 **「打开 XXX」**，库里没有也会去应用索引里找最像的。
- 说 **「baidu.com」**、**「bilibili.com」** 这种，直接当网址打开。
- 说 **「百度 今天天气」**、**「B站 某某」**、**「淘宝 机械键盘」**、**「知乎 xxx」**、
  **「搜索 xxx」**，直接搜。

## 四、匹配是怎么判定的

1. 先把话规整：全角转半角、去标点空格；去掉「请/帮我/我要/麻烦/给我/能不能」这类口头前缀；
   去掉句中的「一下」（打开一下微信 → 打开微信）；去掉「吧/啊/呗/了」这类尾巴。
2. 依次比对：指令名、别名、去掉「打开/启动/运行/唤起」后的名字
   （所以「打开浏览器」会命中「打开Chrome」的别名「浏览器」，而不是猜成 Edge）。
3. 打分：完全相等 1.0；去掉动词后与别名相等 0.94；前缀命中 0.95 起；包含 0.80；字面相似度（Dice 系数）0.85。
4. **≥ 0.86 直接执行**（面板一闪而过）；低于 0.86 就把候选列出来让你挑/回车。
5. 都不像 → 原样送回原窗口。

想调松紧：`%APPDATA%\SayAllVoice\settings.json` 里的 `auto_threshold`（0~100）。

## 五、配置在哪

`%APPDATA%\SayAllVoice\`

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 热键、阈值、是否只走指令、是否开机启动等 |
| `commands.json` | 你自己加的/复制出来的指令 |
| `appindex.json` | 应用索引缓存（7 天自动重建） |
| `sayallvoice.log` | 运行日志，出问题先看这里 |

`settings.json` 常用项：

```json
{
  "hotkey_keys": ["left_control", "left_windows"],
  "manual_hotkey": "ctrl+alt+m",
  "auto_threshold": 86,
  "show_candidates": 5,
  "command_only": false,
  "paste_back": true,
  "start_with_windows": false,
  "beep": true
}
```

- `command_only = true`：没命中指令时**不**把文字送回原窗口（只认指令）。
- `paste_back = false`：同上，效果类似。
- 换语音键：把 `hotkey_keys` 改成别的组合，例如 `["right_control", "right_windows"]`。

## 六、开机自启

托盘右键 → 勾选 **开机启动**（写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
键名 `SayAllVoice`）。不勾就手动双击：

```
%USERPROFILE%\SayAllVoice\SayAllVoice.exe
```

也可以把它放进
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`。

## 七、出问题怎么查

| 现象 | 处理 |
| --- | --- |
| 按语音键完全没反应，微信输入法也不出字 | **SayAll 没在运行**。遥控器语音键由 SayAll 接管，它不开，键就是死的。任务管理器看有没有 `sayall-windows-app.exe`；没有就从开始菜单打开「无线麦 SayAll」，或托盘右键「启动 SayAll（无线麦）」。SayAllVoice 启动时会自动把它拉起来，之后每 20 秒检查一次，掉了就重新拉起 |
| 按语音键没反应，但微信输入法能听写 | 看 `sayallvoice.log` 有没有 `hook installed` 和 `keytrace vk=5B ... injected`；有 keytrace 说明键进来了，没弹面板就带上日志提 Issue |
| 面板弹了但没字 | 微信输入法没进语音状态：先在微信/记事本里按 Ctrl+Win 试听写，确认能出字 |
| 面板抢不到焦点 | 日志里会连续出现 `guard: focus re-asserted`；多半是某个全屏程序在抢前台 |
| 说「打开豆包」打不开 | 点「重建应用索引」，或在指令库里新建一条指向它的路径 |
| 文字进错了窗口 | 属于抢焦点失败，日志有记录；可把 `paste_back` 关掉避免重复输入 |
| 想彻底退出 | 托盘右键 → 退出（不会影响 SayAll 本身） |

## 八、和 SayAll 的关系

- SayAll 负责：遥控器按键 → 合成 Ctrl+Win（SendInput 注入）→ 微信输入法语音。
- SayAllVoice 负责：听到 Ctrl+Win（**包括 SayAll 注入的那种**）→ 弹面板 → 收文字 → 执行指令。
- 两者互不修改；SayAllVoice 不开，一切照旧。
- SayAll 不在时，SayAllVoice 启动会自动把它拉起来（`settings.json` 里 `auto_start_sayall`，默认 true）。
- SayAll 自己的「开机自启」写注册表失败，实际靠 SayAllVoice（在启动文件夹里）开机时把它拉起来。
