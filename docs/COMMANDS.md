## 动态指令（不用配置）

- 「打开 XXX」：库里没有就去开始菜单和注册表的应用索引里找最像的。
- 「baidu.com」「bilibili.com」：直接当网址打开。
- 「百度 今天天气」「B站 某某」「淘宝 机械键盘」「知乎 xxx」「搜索 xxx」：直接搜。
- 「打开 3000」或面板别名：打开本机网页面板，已开就切过去（见 README 的 panels.json）。
- 「A 然后 B」：最多 4 步连续执行。
